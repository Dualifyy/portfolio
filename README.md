# Portfoolio

Üheleheline eestikeelne portfoolio. Staatiline HTML ja CSS, sobib GitHub Pagesi jaoks. Kohandub telefoni, tahvelarvuti ja arvuti ekraaniga.

## Kohalik eelvaade

Ava `index.html` brauseris või käivita projekti kaustas:

```sh
python -m http.server 8000
```

Seejärel ava `http://localhost:8000`.

## GitHub Pages

1. Lisa `index.html` ja `index.css` oma GitHubi repositooriumisse ning lükka muudatused üles.
2. Ava repositooriumi **Settings → Pages**.
3. Vali **Deploy from a branch**, oma põhiharu (näiteks `main`) ja kaust **/ (root)**.
4. Salvesta. GitHub kuvab samal lehel avaldatud portfoolio lingi.

Ehitusprotsessi ega sõltuvuste paigaldamist pole vaja. Kirjatüübid laaditakse Google Fontsist; ühenduse puudumisel kasutatakse süsteemifonte.
